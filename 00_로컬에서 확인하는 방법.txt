💻 PC(로컬)에서 앱 실행 및 확인 메모장


Step 1. PC 명령 프롬프트(CMD) 열기
키보드의 Win + R 누른 후 cmd 입력하고 엔터


Step 2. 로컬 프로젝트 폴더로 이동

cd "C:\Users\장병찬\Desktop\asset"



Step 3. PC에서 Flask 앱 실행

python app.py

실행하면 CMD 창에 Running on [http://127.0.0.1:8501](http://127.0.0.1:8501) 또는 유사한 메시지가 나타납니다.

주의: 테스트하는 동안 이 CMD 창을 닫으시면 안 됩니다.



Step 4. PC 브라우저에서 화면 확인
웹 브라우저(크롬 등) 주소창에 아래 주소를 입력하여 이상이 없는지 테스트합니다.

접속 주소: http://localhost:8501 또는 [http://127.0.0.1:8501](http://127.0.0.1:8501)



Step 5. 테스트 종료
확인이 끝나면 CMD 창에서 Ctrl + C를 눌러 실행을 종료합니다.

이상 없이 동작하는 것을 확인한 후 GitHub에 업로드하고 오라클 서버 업데이트를 진행하시면 됩니다.
